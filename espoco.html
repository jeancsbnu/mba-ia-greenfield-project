GUIA

Como montar essas telas no Figma

arquivo já em uso: FC Tube.fig · mesma biblioteca das telas de login/cadastro (fileKey Doz7n3FsRhfvelYrPhTZAG)

  1. Abra o FC Tube.fig e localize as telas de auth

    São a referência mais próxima de fidelidade: Card, BrandLogo, Input, Label e Button já existem lá com os tokens do DS aplicados de verdade.

  2. Duplique um frame existente como ponto de partida

    Não desenhe do zero. Duplicar o frame de login ou cadastro já traz o Card centralizado, a tipografia e o espaçamento corretos — você só reorganiza o conteúdo de dentro.

  3. Crie um frame por tela, com o nome exato que ele vai ter no inventário

    Use o nome do cabeçalho "Screen:" deste esboço, ex.: Painel de Gerenciamento de Vídeos, Edição de Vídeo. Tamanho desktop 1440 (ou o breakpoint que o time já usa nas telas de auth).

  4. Monte com componentes de verdade, nunca com formas soltas

    Onde este esboço marcou a caixa com borda sólida ciano ("existente"), arraste a instância do componente da biblioteca. Onde marcou borda tracejada âmbar ("novo"), crie um componente novo — mas ainda assim um Component do Figma, não um grupo de retângulos soltos, e ligado aos tokens de cor/tipografia/radius já definidos no arquivo (ver docs/design-system-pillars.md).

  5. Modele estados como variants, não como cópias soltas

    O chip "Rascunho / Publicado" e o toggle de visibilidade devem virar variants de um único componente — é o que mantém o Pilar 3 (Contrato de componente) do design system, e o que faz o /screen-inventory classificar certo depois.

  6. Nunca achate (flatten) ou exporte como imagem

    A extração automática lê a árvore de componentes do Figma, não um screenshot. Um frame achatado em bitmap vira uma tela "vazia" para a ferramenta, mesmo parecendo completa visualmente.

  7. Copie o link de cada frame pronto

    Clique no frame → Share → Copy link to selection. O link já sai no formato ?node-id=…, exatamente o que o próximo passo espera.

  8. Volte aqui e rode o inventário

    Com as URLs das telas em mãos, rode /screen-inventory 04 e cole a lista. O skill extrai os componentes automaticamente e gera o inventário formal — este documento é só o rascunho de apoio, não o substitui.

ordem sugerida se for desenhar aos poucos A-03 (Edição de Canal) é a mais simples — bom primeiro frame para validar o fluxo. Depois A-01 (Painel), que é pré-requisito visual para A-02 (Edição de Vídeo). A-04 (Página Pública) pode vir por último, já que é a única com rota 100% decidida (TD-08) e menos dependência de escolha de layout.
